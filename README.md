# ExploreWorld – React Travel Landing Page

A responsive React + Vite practice project featuring:
- A navigation dropdown menu
- An image carousel with previous/next controls, dots, and automatic sliding
- Destination cards
- A working destination category filter
- Responsive mobile navigation and layout

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this ZIP file.
3. Open the extracted `explore-world` folder in VS Code.
4. Open the terminal in that folder.
5. Run:

   ```bash
   npm install
   npm run dev
   ```

6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

Images are loaded from Unsplash, so an internet connection is needed to display them.
